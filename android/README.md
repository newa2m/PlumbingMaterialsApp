# Android platform files

يتم توليد ملفات Android القياسية تلقائيًا في GitHub Actions بواسطة:

```bash
flutter create --platforms=android --project-name plumbing_takeoff .
```

هذا مقصود حتى تبقى ملفات المنصة المولدة متوافقة مع نسخة Flutter المستقرة على خادم GitHub، مع عدم الحاجة إلى تثبيت Flutter أو Android Studio على جهاز Windows.
