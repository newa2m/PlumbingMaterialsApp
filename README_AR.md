# حصر خامات السباكة — تصور وتجهيز Flutter

الملفات الأصلية (`index.html` وملفات الاختبار) محفوظة كما هي كمرجع للتصميم والسلوك. تمت إضافة مشروع Flutter مستقل في `pubspec.yaml` و`lib/` و`test/`.

## تشغيل مشروع Flutter

يتطلب Flutter SDK حديثًا (Dart 3.3 أو أحدث):

```bash
flutter pub get
flutter test
flutter run
```

## البناء على GitHub Actions بدون تثبيت محلي

ملف `.github/workflows/android.yml` يثبت Flutter وJava، يهيئ ملفات Android، يقبل تراخيص Android، ثم يشغل `flutter pub get` و`flutter analyze` و`flutter test` و`flutter build apk --debug` ويرفع APK كـ Artifact. لا يحتاج الجهاز المحلي إلى Android Studio أو Flutter SDK.

للاستخدام: أنشئ مستودعًا خاصًا فارغًا في GitHub، اربطه بالمجلد المحلي، نفّذ `git add .` ثم `git commit -m "Initial Flutter app"` ثم `git push -u origin main`. من تبويب **Actions** شغّل **Flutter Android CI** يدويًا أو ادفع commit جديدًا. بعد نجاح التشغيل افتح صفحة التشغيل، وانزل إلى **Artifacts** ثم نزّل `plumbing-takeoff-debug-apk` وافتح الملف المضغوط لاستخراج `app-debug.apk`.

لا يُعد البناء ناجحًا من جهة هذا المشروع قبل ظهور حالة خضراء لكل خطوات Workflow داخل GitHub Actions؛ لم يتم تشغيله من هذه البيئة لأنه لا يوجد مستودع GitHub أو بيانات اعتماد مرتبطة بالمشروع.

يستخدم التطبيق SQLite محليًا عبر `sqflite`، ويهيئ جداول المشروعات والأماكن والخامات والكتالوج عند التشغيل الأول.

افتح `index.html` في متصفح حديث. هذا نموذج تفاعلي وليس تطبيق APK.

## طريقة الاستخدام
- اختر **حصر سريع الآن** لإنشاء قائمة مباشرة بمكان افتراضي «عام»، ويمكن تحويلها لمشروع بإكمال البيانات.
- أو اختر **معاينة مشروع جديد** لإدخال اسم المشروع والعميل والعنوان، ثم أضف الأماكن.
- أضف خامات بالمقاس والوحدة والكمية. راجع البنود وعدلها قبل الاعتماد.
- تقرير **قائمة الشراء** يدمج البنود ذات الاسم والمواصفة والوحدة المتطابقة، وتقرير **حسب المكان** يعرض التفاصيل.
- يمكن طباعة التقرير أو حفظ PDF باستخدام حوار الطباعة، وتنزيل CSV يفتح في Excel.
- من الإعدادات نزّل نسخة احتياطية JSON بشكل دوري؛ التخزين محلي في المتصفح.

## ما تم اختباره
- اختبارات JavaScript آلية: حالة بدء فارغة، تجميع المقاسات، منع الكميات السالبة، إلغاء الاعتماد بعد التعديل، التخزين.
- تعذّر تشغيل الاختبار التفاعلي بمتصفح Chromium في البيئة الحالية (حجب تحميل localhost وملفات file://)، ويلزم اختبار فعلي على جهاز المستخدم.

## حدود النسخة
- بدون تسجيل صوتي أو التعرف على صور الخامات أو قاعدة بيانات SQLite.
- لا يوجد XLSX أصلي أو PDF مولّد مباشرة (الطباعة عبر المتصفح).
- الأسعار والمصنعية وإدارة الموردين لم تُنفذ بعد.
- بيانات المتصفح قد تضيع عند حذف بيانات الموقع؛ لذلك النسخ الاحتياطي ضروري.
